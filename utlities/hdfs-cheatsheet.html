$ man hdfs

HDFS Command Reference

Every command uses the hdfs dfs prefix (the legacy hadoop fs form still works identically). Search or filter by category below.

File & directory basics

hdfs dfs -ls /path
List directory contents.
hdfs dfs -ls -R /path
List directory contents recursively.
hdfs dfs -mkdir /path
Create a directory.
hdfs dfs -mkdir -p /path/to/dir
Create a directory along with any missing parent directories.
hdfs dfs -rm /path/file
Remove a file (moves it to trash if enabled).
hdfs dfs -rm -r /path
Remove a directory and its contents recursively.
hdfs dfs -rm -skipTrash /path/file
Delete a file permanently, bypassing trash.
hdfs dfs -rmdir /path
Remove a directory only if it's empty.

Copying data

hdfs dfs -put localfile /hdfs/path
Copy a file from the local filesystem into HDFS.
hdfs dfs -copyFromLocal localfile /hdfs/path
Equivalent to -put, copies local file into HDFS.
hdfs dfs -get /hdfs/path localfile
Copy a file from HDFS down to the local filesystem.
hdfs dfs -copyToLocal /hdfs/path localfile
Equivalent to -get, copies HDFS file to local disk.
hdfs dfs -cp /src/path /dst/path
Copy a file or directory within HDFS.
hdfs dfs -mv /src/path /dst/path
Move or rename a file or directory within HDFS.
hdfs dfs -getmerge /hdfs/dir localfile.txt
Merge all files in an HDFS directory into a single local file.

Viewing file content

hdfs dfs -cat /path/file
Print the full contents of a file to stdout.
hdfs dfs -tail /path/file
Show the last kilobyte of a file's contents.
hdfs dfs -cat /path/file | head
Pipe output to view just the first lines of a file.
hdfs dfs -text /path/file
Print a file as text, auto-decompressing gzip/Avro/SequenceFile input.

File info & sizes

hdfs dfs -du /path
Show disk usage for files/directories under a path.
hdfs dfs -du -h /path
Same as above, with human-readable sizes (KB/MB/GB).
hdfs dfs -du -s -h /path
Show a single summarized total size for a path.
hdfs dfs -df -h
Show overall filesystem capacity and usage across the cluster.
hdfs dfs -count /path
Count directories, files, and total bytes under a path.
hdfs dfs -count -h /path
Same count, formatted in human-readable units.
hdfs dfs -test -e /path/file
Test whether a path exists (use -d/-f for directory/file checks).

Permissions & ownership

hdfs dfs -chmod 755 /path
Change permissions on a file or directory.
hdfs dfs -chmod -R 755 /path
Change permissions recursively.
hdfs dfs -chown user:group /path
Change the owner and group of a path.
hdfs dfs -chown -R user:group /path
Change owner and group recursively.
hdfs dfs -chgrp group /path
Change the group of a path.

Replication & blocks

hdfs dfs -setrep -w 3 /path/file
Set replication factor for a file and wait for it to complete.
hdfs fsck /path/file -files -blocks -locations
Inspect block locations and health for a specific file.

Admin & cluster health — run as HDFS superuser

hdfs fsck /
Run a filesystem check across the whole cluster.
hdfs dfsadmin -safemode get
Check whether the NameNode is currently in safe mode.
hdfs dfsadmin -safemode enter
Manually put the NameNode into safe mode.
hdfs dfsadmin -safemode leave
Take the NameNode out of safe mode.
hdfs dfsadmin -report
Print a cluster-wide capacity and DataNode status report.
hdfs dfsadmin -refreshNodes
Reload the list of allowed/excluded DataNodes.
hdfs balancer
Rebalance data blocks evenly across DataNodes.
hdfs dfsadmin -printTopology
Print the rack/DataNode topology of the cluster.

Trash

hdfs dfs -expunge
Permanently empty the trash immediately.
hdfs dfs -ls /user/$USER/.Trash
List what's currently sitting in trash.
